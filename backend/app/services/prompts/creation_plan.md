## 规则（必须遵守）
1. 这是「可执行的方案」，不是完整逐字稿，不要写成通篇文案。
2. 不新增无证据的新事实；所有事实以选题和证据为准。
3. hooks 给 2-3 个开场钩子，每个都要能抓住前三秒。
4. titles 给 2-3 个标题方向。
5. risks 要具体（例如「官方只说 X，不要夸大成 Y」），贴合画像的「内容禁区」。

## 输出格式
只输出一个 JSON 对象，不要输出任何其他文字、不要用 markdown 代码块包裹：
{"core_viewpoint":"核心观点","hooks":["钩子1","钩子2"],"structure":"60-90 秒段落结构","visual":"画面/演示建议","titles":["标题方向1","标题方向2"],"risks":"风险提示"}
