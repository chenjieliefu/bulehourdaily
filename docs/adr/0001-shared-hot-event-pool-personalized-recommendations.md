# 使用共享热点事件池，在建议层完成个性化

微蓝日报采用统一的固定信息源和共享热点事件池；通用日报与个性化日报引用同一组事件、证据和可信度结论。个性化只发生在事件选择、发布价值判断、切入角度和创作方案层，不为每位创作者独立采集事实。

这一选择牺牲了创作者自定义来源的自由度，但能在邀请制 MVP 阶段控制采集复杂度、模型成本和事实一致性，并把付费价值集中在“今天什么最适合我的账号”。只有当 AI 抖音场景达到至少 20 位持续付费创作者，且共享事件池的质量和运营流程稳定后，才重新评估个人信息源或新的领域事件池。

## Considered Options

- **每位创作者维护独立来源并独立生成**：个性化更强，但采集、去重、证据校验和成本会随用户数增长，首版不采用。
- **所有人接收完全相同的日报**：事实一致且成本最低，但无法形成个性化付费价值，不采用。

## Consequences

- 信息源、事件聚类和证据质量会同时影响所有创作者，必须保留发布前质检。
- 个性化内容不得生成共享事件池之外的新事实，也不得改变可信度标签。
- 创作者配置的核心对象是创作者画像，而不是信息源列表。
- 舞蹈等新领域需要独立的信息源池、评分规则和内容模板，不能只向现有池增加关键词。
