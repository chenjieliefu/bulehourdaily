# 运营工作台上线说明

日期：2026-08-20  
范围：运营工作台、产品反馈、站点内容运营、运营身份与会话修复

## 1. 本次上线内容

### 运营工作台

运营者登录后进入 `/ops`，整套页面均属于运营工作台。侧栏按以下业务域组织：

1. 总览：运营概览、异常和待办。
2. 内容运营：今日日报、候选事件、日报记录。
3. 个性化运营：个性化内容、邮件送达。
4. 创作者运营：创作者、订阅管理、邀请码。
5. 反馈：产品反馈、发布反馈。
6. 站点运营：产品介绍、会员页面。
7. 系统：信息源、采集状态、任务记录。

### 数据与接口

- 新增运营概览、创作者汇总、个性化内容、邮件送达、订阅、反馈和任务记录接口。
- 新增产品反馈模型、公开提交接口和运营状态处理接口。
- 新增站点内容模型；产品介绍和会员页支持草稿、发布、回滚，公开页面只读取已发布内容。
- 信息源写操作统一要求运营者身份。
- 新增 `GET /api/v1/auth/me`，由服务端返回当前令牌对应的用户与角色。

### 权限与会话

- 运营权限以数据库中的 `User.is_operator` 为准。
- 运营账号与普通创作者账号使用独立浏览器会话，避免同域多标签登录相互覆盖。
- 工作台加载时再次向服务端校验运营角色；旧版错配状态会被清理并要求重新登录。
- 运营账号不会出现在创作者运营列表中，也不能被开通创作者订阅。
