# 第 5 阶段技术开发文档｜创作方案 + 发布反馈 + 邮件 + 人工订阅

> 配套文档：《微蓝日报 PRD》、《通用技术栈手册》、《技术适配声明》。
> 本文档只覆盖第 5 阶段。

## 一、阶段目标

对齐 PRD「一周 MVP 交付计划」的 **Day 6**，以及 **FR-12、FR-13、FR-14、FR-15**。

- **交付范围**：
  1. 创作方案：创作者展开当天任一个性化选题，生成详细创作方案（FR-12）。
  2. 发布反馈：对选题标记「想做 / 不感兴趣 / 已发布」，已发布可附抖音链接（FR-13）。
  3. 邮件送达：生成个性化日报后发邮件，MVP 用**本地模拟发送**（记录+日志，不接真 SMTP）（FR-14）。
  4. 人工订阅：运营者人工开通订阅，¥49 标准价 / 前 50 位创始 ¥29，不接自动支付（FR-15）。
- **阶段产物**：从「看个性化日报 → 展开创作方案 → 标记发布 → 收到邮件 → 可被人工开通订阅」的闭环。
- **明确不做**：自动支付、多档套餐、微信/飞书推送、收藏（P1）、质检页（阶段 6）。
- **主链路**：`个性化选题 → 展开创作方案 → 标记反馈 → （模拟）邮件送达 → 运营者人工开通订阅`。

## 二、技术适配摘要

- 采用：FastAPI、Pydantic、SQLAlchemy、pytest、LLM 调用层、JWT 鉴权（已有）。
- 启用：创作方案 LLM 生成；邮件本地模拟（无外部服务）；订阅人工操作（无支付）。
- 开发路径：后端先行 + 前端页面扩展。

## 三、技术栈与模型

- 创作方案生成：DeepSeek（同一 LLM 客户端，mock 模式不变）。
- 邮件：本地模拟（写 MailDelivery 记录 + 日志），不引入 SMTP/第三方邮件服务。
- 订阅：人工数据操作，无支付集成。

## 四、环境与配置

- 无新增外部依赖、无新 Key。

### 状态与规则（确定性）

- **反馈**：同一「用户+选题」只有一个当前状态，可修改；`published` 时可选填抖音链接。
- **创作方案**：每天最多展开当天的 3 个选题；生成失败可重试，不重复计权益；一份选题一份方案。
- **订阅资格**：体验 = 3 份个性化日报（已有）；订阅 active = 无体验次数限制。阶段 5 接入后：生成个性化日报时，`有有效订阅` 或 `体验次数未满` 二选一。
- **邮件**：MVP 模拟发送；不真发、不触发额外邮件（当日补充不发）。

## 七、API / 工具设计

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| POST | /api/v1/topics/{id}/plan | 生成创作方案（长任务，提交+轮询） | 是 |
| GET | /api/v1/topics/{id}/plan | 获取创作方案 | 是 |
| PUT | /api/v1/topics/{id}/feedback | 提交/修改反馈 | 是 |
| GET | /api/v1/subscriptions/me | 我的订阅状态 | 是 |
| POST | /api/v1/subscriptions | 运营者人工开通订阅（MVP 无独立鉴权，本地直调） | 运营者 |

- 订阅的「人工开通」MVP 用受保护接口直调（本地）；正式运营后台在阶段 6 质检页一并做。

## 八、Prompt 设计（creation_plan.md）

- 角色：把个性化选题扩展成可拍摄的创作方案。
- 输入：创作者画像摘要 + 个性化选题全部字段 + 证据链接。
- 输出 JSON：`{"core_viewpoint","hooks":["...","..."],"structure","visual","titles":["...","..."],"risks"}`。
- 约束：不是完整逐字稿；不新增无证据事实；风险要具体（如「官方只说 X，别说成 Y」）。

## 九、验收界面

「我的日报」页的每个个性化选题卡新增：
1. 「**展开创作方案**」按钮 → 轮询生成 → 展开方案（核心观点/钩子/结构/画面/标题方向/风险）。
2. 「**想做 / 不感兴趣 / 已发布**」三个反馈按钮，已发布时弹输入框填抖音链接。
3. 订阅状态显示（体验剩余份数 / 订阅有效期）。

## 十、测试要求

### 第一层 mock 测试（离线）

1. 创作方案生成（mock）：引用选题+证据，字段齐全；同一选题重复生成覆盖不重复计。
2. 反馈：同一选题一个状态、可修改；published 需可带链接。
3. 邮件：生成个性化日报后自动产生 MailDelivery 记录（模拟 sent）。
4. 订阅：人工开通 active；active 用户生成个性化日报不受 3 份限制；价格类型不可改历史。
5. 权限：A 不能展开/反馈 B 的选题。

### 第二层真实冒烟（验收前）

- 真实 DeepSeek 跑通：`个性化选题 → 生成创作方案 → 查看方案`，检查钩子/结构/风险质量。

## 十一、验收清单（产品经理可照做）

- [ ] 登录后进「我的日报」，点某个选题的「展开创作方案」，能等到一份方案（核心观点/钩子/结构/画面/标题方向/风险）。
- [ ] 方案不是完整逐字稿（有结构建议而不是成篇文案）。
- [ ] 对选题点「想做」「不感兴趣」，状态能保存和切换；点「已发布」能填抖音链接。
- [ ] 生成个性化日报后，能看到「邮件已发送（模拟）」的提示。
- [ ] 体验用完 3 份后，除非运营者开通订阅，否则不能继续生成。
- [ ] 运营者开通订阅后（我演示给你看），该账号可继续生成。

## 十二、风险与待确认项

- **邮件为本地模拟**：商业上线前需接真实邮件供应商（见 PRD 开放项）。
- **订阅为人工操作**：无自动支付；价格、发票、退款规则上线前确定。
- 需要产品经理决定的问题：无。
